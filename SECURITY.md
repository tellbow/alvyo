# Security

Report a vulnerability privately, not in an issue: a bug report from the
app or the website («Fehler melden») becomes a public GitHub issue.
Use GitHub's «Report a vulnerability» on the repository's Security tab, or
write to the maintainer directly.

Say what is affected (website, API, iOS app), how to reproduce it and what
an attacker gains. You get an answer within a week.

Only the current release (https://alvyo.tellbow.ch and the latest app build)
is supported; fixes are released as a patch version.
